# Construction Company Management System

Production-oriented MERN foundation for a multi-tenant construction management SaaS.

## Structure
- `client/` React + Vite frontend
- `server/` Express + MongoDB API

## Development
1. Copy `server/.env.example` to `server/.env` and configure secrets.
2. Install dependencies with `npm install` at the repository root.
3. Run `npm run dev`.

Never commit `.env` files or production credentials.
